# المرحلة السادسة — الإلغاء والتصحيح قبل الاستلام

الحالة: **ضوابط التنفيذ المحلية جاهزة للمراجعة؛ لا يعني ذلك إغلاق المسائل التي تحتاج قرارًا من مالك القواعد.**

## القرار لكل حالة

| الحالة | السلوك المعتمد في التنفيذ |
|---|---|
| مسودة مصروف لم تُرسل | يمكن حذف المسودة المتاح حذفها؛ لا تُنشأ حركة عهدة. المصروف المرسل لا يُحذف. |
| مصروف مرفوض | يظهر كـ **رفض** مع السبب والفاعل والتوقيت. يعكس النظام خصم الإرسال مرة واحدة بحسب مسار المصروف القائم. |
| طلب تمويل مرفوض | لا ينشأ قيد مالي ولا عكس. يمكن لمدير الفرع إعادة إرسال الطلب نفسه عبر المسار البنكي؛ يُحفظ الرفض السابق في سجل الأحداث. |
| تحويل بنكي نُفّذ ولم يؤكد المدير استلامه | يظل التنفيذ ظاهرًا بانتظار تأكيد الاستلام؛ لا يُعرض كملغى ولا يزيد رصيد الفرع قبل تأكيد المدير. |
| تمويل نقدي أنشأه مدير الفرع | إنشاء الطلب النقدي والتنفيذ وإعادة إرساله موقوفة إلى أن يُعتمد عقد إثبات التسليم. يظل التحويل البنكي متاحًا. |
| تسليم مباشر من مالك العلامة | يبقى في مساره المنفصل؛ لم يتغير هذا المسار. |
| مصروف معتمد أو تمويل استلمه الفرع | لا يوجد إجراء إلغاء مالي عام. لا حذف ولا عكس تلقائي؛ يلزم قرار قواعد معتمد قبل إضافة مسار عكسي. |
| أثر تاريخي غير صحيح | لا تُعدّل القيود التاريخية تلقائيًا. تُطابق الحركة ومصدرها أولًا، ثم تُعالج بتسوية موثقة ومعتمدة خارج هذا التغيير. |

## التغييرات

- أضيف سجل `rejection` مستقل في تفاصيل المصروف وطلب التمويل. بقي حقل `cancellation` كاسم توافق قديم معلّمًا `deprecated_alias_of: rejection` كي لا تسيء الإصدارات الأقدم تفسير بيانات الرفض. لا ينشئ هذا الحقل إجراء إلغاء.
- تُظهر تطبيقات Flutter بيانات الرفض من العقد الجديد، مع توافق قراءة مؤقت للعقد القديم عند حالة الرفض فقط.
- أصبحت شاشة إنشاء طلب تمويل مدير الفرع تعرض التحويل البنكي فقط. بقي اختيار النقد متاحًا لمسارات التسليم الأخرى المنفصلة.
- أضيفت إعادة إرسال طلب التمويل المرفوض على معرّفه نفسه من شاشة التفاصيل، بعد أن يتيحها الخادم. تُحدّث الشاشة من الخادم بعد الإرسال قبل إظهار النتيجة.
- يرفض الخادم إنشاء طلب تمويل نقدي جديد من مدير الفرع، ويرفض تنفيذ أو إعادة إرسال الطلبات النقدية القديمة. لا يُمسّ مسار التسليم المباشر من مالك العلامة.
- حذف المسودة لا يغيّر سجل العهدة، وحذف المصروف بعد الإرسال مرفوض.
